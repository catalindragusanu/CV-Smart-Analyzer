JOB TITLE: Frontend Developer - React
COMPANY: Digital Experience Labs
LOCATION: Seattle, WA

We're looking for a creative Frontend Developer with strong React skills to build beautiful, responsive user interfaces for our web applications.

React, JavaScript, TypeScript, HTML5, CSS3, Redux, Next.js, Responsive Design, Git, REST APIs, Webpack, npm, Material-UI, Tailwind CSS

- Optimize application performance and load times
- Ensure cross-browser compatibility
- Write clean, maintainable, and well-documented code
- Collaborate with backend developers for API integration
- Participate in code reviews and team meetings
- Implement accessibility standards (WCAG)

- Bachelor's degree in Computer Science or equivalent experience
- 3+ years of professional frontend development experience
- Expert knowledge of React and modern JavaScript (ES6+)
- Strong proficiency in TypeScript

- Solid understanding of HTML5, CSS3, and responsive design
- Experience with modern build tools (Webpack, Vite)
- Knowledge of RESTful APIs and asynchronous programming
- Strong attention to detail and design sensibility

BONUS POINTS:
- Experience with Next.js or server-side rendering
- Knowledge of testing frameworks (Jest, React Testing Library, Cypress)
- Familiarity with design tools (Figma, Adobe XD)
